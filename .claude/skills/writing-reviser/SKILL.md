# Writing Reviser

## Core Constraint
Never fabricate: no invented experiment results, no hallucinated citations.
For new references, invoke /research-lit to fetch real papers only.
If a revision requires new experimental data, mark it as NEEDS_AUTHOR
and skip — do not invent numbers or results.

## Inputs
- `paper/main.tex` (or path from $ARGUMENTS)
- `review_output.md` (generated by /paper-reviewer)

## Step 1 · Parse review_output.md

Read `review_output.md` and classify every revision priority into three buckets:

**SAFE** — can be automatically fixed (no new data needed):
- Placeholder text (venue, year, author fields)
- Writing clarity, sentence restructuring, grammar
- Section reorganization
- Related work expansion (use /research-lit for real citations)

**MARK** — cannot be automatically fixed, must flag for author:
- Fabricated or unverifiable identifiers (model names, version numbers)
- Missing variance values in tables
- Any claim requiring new experimental runs

**SKIP** — route to other skills:
- Figure issues → output to `figure_todo.md` for /figure-advisor
- Ablation studies → output to `author_todo.md`

## Step 2 · Apply revisions

For each SAFE item, edit `paper/main.tex` directly.

For every change, wrap it in a LaTeX comment tag:
```latex
% [REV-001] Fixed: venue placeholder
\end{document} → removed "Conf'XX, June 03-05, 2018"
```

Rules:
- Preserve the author's voice — restructure only what's needed
- For Related Work expansion: invoke `/research-lit "[topic]"` first,
  use only papers it returns, never invent citations
- Add `\cite{PLACEHOLDER_REV_NNN}` for new refs the author must verify

For each MARK item, insert a comment in the .tex file:
```latex
% [NEEDS_AUTHOR] REV-003: Replace "Claude-Opus-4.5" with actual
% model version used in your experiments. Do not leave as-is.
```

## Step 3 · Generate writing_report.md

Write `writing_report.md` with this structure:

```markdown
# Writing Revision Report

## Changes Applied (SAFE)

| ID | Location | Before | After |
|----|----------|--------|-------|
| REV-001 | Line 423, \end{document} | "Conf'XX, 2018" | "[VENUE], 2025" |
| REV-002 | Section 1, para 2 | "..." | "..." |

## Flagged for Author (MARK)

| ID | Location | Issue | Action needed |
|----|----------|-------|---------------|
| REV-003 | Section 5.3, Table 3 | Fabricated model identifiers | Replace with real versions |

## Routed to Other Skills (SKIP)

- figure_todo.md → /figure-advisor (N items)
- author_todo.md → requires new experiments (N items)
```

## Step 4 · Output files

- `paper/main_revised.tex` — revised paper
- `writing_report.md` — change log with before/after
- `figure_todo.md` — items for /figure-advisor
- `author_todo.md` — items requiring author action
